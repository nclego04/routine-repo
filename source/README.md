# Course sources (mirrored)

Problem sets, solutions, and lecture transcripts from **MIT OpenCourseWare,
RES.6-007 *Signals and Systems*** (Prof. Alan V. Oppenheim), Spring 2011.

Source: https://ocw.mit.edu/courses/res-6-007-signals-and-systems-spring-2011/
License: Creative Commons BY-NC-SA 4.0
(https://creativecommons.org/licenses/by-nc-sa/4.0/)

Mirrored here so the morning briefing routine reads them from the repo rather
than fetching ocw.mit.edu, which the routine's sandbox blocks. Extracted from
the official course archive (`res_6-007-spring-2011.zip`), which ships the
transcripts under opaque YouTube-ID filenames; each was matched to its lecture
by the `MITOCW | MITRES_6-007S11lecNN_300k.mp4` marker on page 1 and renamed.

## Layout

- `psets/MITRES_6_007S11_hwNN.pdf`      — problem set NN      (26 files)
- `psets/MITRES_6_007S11_hwNN_sol.pdf`  — solutions for NN    (26 files)
- `transcripts/lecNN_transcript.pdf`    — lecture NN transcript (26 files)

Lectures and problem sets 01–26, complete. No fetch step is required to
regenerate; re-download the archive from the link above if ever needed.
