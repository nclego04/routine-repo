# Review-problem prompt (paste-in at a phase checkpoint)

*Companion to `dsp-audio-plan.md` and `cards.md`. Use at a phase checkpoint — the ✅ lines
closing DSP 501–505, plus Week 16 Day 3 and Week 28 Days 1–2, which already run a full-chain
or full-deck pass — to work a short interleaved problem set instead of, or alongside, a cards
pass. Cards test whether you can still state a fact; this tests whether you can still execute
the derivation. Does not add a study day: it fills the checkpoint day the plan already reserves.
Pick 3–4 problems from at least two non-adjacent earlier weeks — weight toward whichever weeks
have gone longest untouched, or whichever concept has a logged error pattern in `LOG.md` or
`cards.md`. Solutions from the archived pset PDFs in `source/` aren't needed for selection, only
for your own self-check after.*

> I'm running a phase-checkpoint review, not new material. Below the line are 3–4 problem
> statements pulled from at least two non-adjacent earlier weeks — **[name the weeks, or paste
> the statements directly]**. This checkpoint is **[DSP 50X Checkpoint / Week 16 / Week 28]**.
>
> Work these exactly like a new pset: full derivation, one Socratic question at a time, restate
> the full problem before the first question so I can write it down. No shortcuts because I've
> "done this before" — if I stall, ask a question that lets me find the next move myself rather
> than stating it. Don't tell me whether an answer is right or wrong until I've committed to it.
>
> After each problem, name the concept it exercises in one clause, so a miss can become a
> `cards.md` entry the normal way. At the end, give me one line: which of these (if any) needs a
> fresh card, and which weeks are now confirmed still solid.

**The line you never cross:** this re-derives something already covered, it does not teach
ahead. If a pulled problem turns out to need content past this checkpoint, drop it and pick
another rather than covering new ground early.

## Why this exists

`cards.md` keeps atomic facts, definitions, sign conventions, small identities alive cheaply
because a card costs seconds. It was never meant to test whether the actual derivation muscle
survives a ten-week gap, and the plan's own habit line says as much: "you will not touch the
orthogonality principle between Week 6 and Week 17." A card can confirm you remember what the
orthogonality principle *is*; it can't confirm you can still produce `w = R⁻¹p` from a blank
page. That's what this prompt is for, and it only runs at checkpoints the plan already has, so
it costs no new days and doesn't compete with the pace risk that's already the plan's top-listed
problem.
